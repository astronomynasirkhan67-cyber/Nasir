# NK Voice AI

Vosk (speech to text) -> Gemma via MediaPipe (reply) -> Android TextToSpeech (voice).

1. Push this folder to GitHub (main branch).
2. Actions tab -> "Build APK" -> download artifact NKVoiceAI-APK.
3. Install the APK. First launch: download Vosk models, then add the Gemma model (link or file).
4. After that everything runs offline.
