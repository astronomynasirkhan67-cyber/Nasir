# NK Voice AI

Android voice assistant and a Windows desktop companion.

- Android app: existing project at repository root.
- Windows desktop source: `desktop/`.
- Android APK workflow: `.github/workflows/build.yml`.
- Windows installer workflow: `.github/workflows/build-windows.yml`.

Push to GitHub, then open **Actions** to download the build artifacts. See `README-WINDOWS.md` for Windows installer and offline model details.
