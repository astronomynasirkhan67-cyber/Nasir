# NK Voice AI — Android + Windows Desktop

This repository contains:
- `Nasir-main/`: the existing Android NK Voice AI project.
- `desktop/`: a Python Windows desktop version designed for offline use with a local GGUF model.

See `desktop/README.md` for Windows setup and model instructions. The Android app's `.litertlm` model is not directly compatible with the desktop GGUF runtime, so the desktop version requires its own compatible GGUF model file.
