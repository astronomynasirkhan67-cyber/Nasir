# NK Voice AI — Windows Desktop build

This repository keeps the existing Android app and adds a Windows desktop companion under `desktop/`.

## Build the Windows installer with GitHub Actions
1. Push this repository to GitHub.
2. Open **Actions** and run **Build NK Voice AI Windows Installer** (or push to `main` / `master`).
3. Open the completed workflow run and download the `NKVoiceAI-Windows-Installer` artifact.
4. The artifact contains the Windows installer generated by Inno Setup.

## Windows 7 compatibility note
The workflow uses a legacy Windows runner and pinned older Python packages to aim for Windows 7 compatibility. Windows 7 must be Service Pack 1 and fully updated. GitHub runner images, compiler toolchains, model runtimes, and hardware vary; this build cannot guarantee that every PC/Windows 7 installation will run it. Test the installer on the target computer. If the llama.cpp native dependency cannot build, the workflow will fail and its Actions log will show the exact step.

## Offline use
- The installer does **not** bundle multi-gigabyte AI or speech models.
- First, download a compatible instruction-tuned **GGUF** model and select it using **Choose GGUF Model**. Once downloaded and loaded, chat inference runs locally without internet.
- Optional speech input requires a separately downloaded/extracted Vosk model. The included voice input path is only as good as the language model selected; an Urdu Vosk model is not included.
- Text-to-speech uses voices installed in Windows. Urdu speech output depends on an Urdu voice being installed on the PC.
- Package installation and model download require internet the first time. Later local inference does not require internet.

## Desktop development
See `desktop/README.md`. The Android LiteRT `.litertlm` model is not directly loadable by this desktop GGUF runtime.

### Optional Qwen3 embeddings
The desktop app now has **Load Qwen3 Embeddings** for optional in-session semantic recall. The uploaded Qwen3 repository ZIP is only a notebook/code recipe, not the model weights. Download a compatible `.gguf` embedding model separately from https://huggingface.co/Qwen/Qwen3-Embedding-0.6B-GGUF . A separate instruction-tuned GGUF chat model is still required for responses. Model files are intentionally not bundled in this source ZIP.
